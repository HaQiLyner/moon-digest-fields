# Changelog

## 0.2.0 - 2026-09-23

- Add binary-safe incremental and one-shot SHA-512.
- Generate and verify combined SHA-256/SHA-512 fields.
- Add framework-neutral HTTP header lookup, combination, replacement, and verification.
- Negotiate algorithms directly from repeated Want-* header fields.
- Add a 2,500-message gateway scenario and 20,000-message dual-digest workload.

## 0.1.0 - 2026-09-21

- Parse and canonicalize RFC 9530 digest and preference fields.
- Generate and verify SHA-256 fields with policy and batch audit support.
