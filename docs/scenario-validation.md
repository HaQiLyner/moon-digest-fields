# 场景验证与复现

## 可靠性场景：制品下载网关

测试文件 `scenario_test.mbt` 构造 2000 条捕获记录，并调用真实的字段解析、
Base64 解码、SHA-256 和策略判定路径。

| 输入类别 | 条数 | 预期结果 |
|---|---:|---|
| 摘要与正文一致 | 1600 | `Verified` |
| 摘要对应另一正文 | 200 | `Mismatch` |
| 非法 Base64 字段 | 100 | `InvalidField` |
| 缺少摘要字段 | 100 | `MissingField` |

复现命令：`moon test --target js`。2026-09-21 在 MoonBit
`moonc v0.10.12+1634b282e` 上结果为 11/11 测试通过。测试还覆盖 RFC 9530
已知向量、分块计算、单字节内容改变、算法协商、过时算法策略和资源上限。

## 性能工作负载

`examples/bench` 使用 64 字节正文，对“解析字段 + Base64 解码 + SHA-256 +
摘要比较 + 结果分类”的完整路径连续执行 20000 次。

```sh
moon run examples/bench --target js
```

本机 Windows/JavaScript 后端的一次实测为：20000/20000 条通过，228 ms，约
87719 条/秒。结果会随 CPU、运行时和后台负载变化；验收重点是命令可复现、
校验总数完整且无错误，而不是固定吞吐阈值。

## 内容与表示边界

- `Content-Digest` 校验实际 HTTP 消息内容字节；
- `Repr-Digest` 校验选定表示字节；
- 本库不会猜测或自动解压内容编码，调用方负责传入语义一致的字节；
- 批量审计保留每条记录的稳定代码，便于告警、统计和取证。
