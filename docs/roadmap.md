# 开发路线图

## 0.1（当前）

- RFC 9530 四类字段的严格解析与稳定输出；
- SHA-256 一次性和分块计算；
- 验证策略、资源限制、协商与批量审计；
- 四后端 CI、已知向量、篡改测试和可复现场景。

## 0.2

- 增加 SHA-512 计算与多算法联合验证；
- 提供面向 HTTP 框架的无绑定适配示例；
- 扩充 Structured Fields 兼容性语料和模糊测试。

## 0.3

- 为流式文件/网络读取提供回调式适配层；
- 输出机器可读审计统计；
- 与 HTTP Message Signatures 组合展示“先摘要、后签名”的流程。

不计划在核心包内实现 HTTP 栈、TLS、身份认证或内容解压，以保持职责清晰。
